The Creative Signal: RS Hundal's AI Studio

How to install the course on your own device, start learning, keep your work safe and get updates.

Two ways to use the course

  • Install it from the web address your instructor gives you. This works on computers, phones and tablets. After the first visit it works offline and updates itself.
  • Offline copy (zip file), for computers. No internet or install needed: unzip it and double-click index.html.

Use the offline copy (zip)

  1. Download Creative-Signal-offline-v….zip from your instructor.
  2. Unzip it first (Windows: right-click → Extract All; Mac: double-click it). Don't run it from inside the zip.
  3. Open the Creative-Signal folder and double-click index.html. It opens in your browser.
  4. Keep the folder in the same place and open it with the same browser every time, so your progress is there.

Phones and tablets can't open the zip copy properly. Use the web address on those.

First run

  1. On the opening page, click Enter the studio.
  2. Under I'm new here, type your name, click Create profile & start and choose a 4–6 digit PIN. Remember it: you'll need it each time you come back.
  3. Start Level 1. Each lesson is a short read followed by a hands-on challenge. The lesson counts once you pass the challenge.

Forgotten your PIN? Your instructor can reset it, but only on the same device and browser where your profile is.

Where your work is saved

Your progress stays on the device you're using, in that browser. It isn't uploaded anywhere and doesn't sync on its own.

  • The installed app, a different browser and the offline zip copy each keep separate progress.
  • Clearing your browser's history or site data, uninstalling the app, or using a private/incognito window can erase it.
  • On iPhone and iPad, Safari may clear data for websites you haven't used for a few weeks. Installing to the Home Screen avoids most of this, but back up anyway.

Back up and move to another device

  1. Sign in, open your name (top right) → Profile & backup → Export my backup. A .json file is saved, usually to Downloads. On an installed iPhone/iPad app, the Share sheet opens: choose Save to Files.
  2. On the new device, open the course, go to the sign-in page and choose Restore a profile from a backup file. Your PIN comes with it.
  3. Export again at the end of each session. A backup is a snapshot, not live syncing.
  4. Your instructor may ask you to send your backup file so they can review your progress.

The backup file isn't encrypted. Keep it private.

Updates

  • Installed / web version: new course content downloads by itself. When it's ready you'll see Update ready. Click Reload to update. Your progress is kept.
  • Offline zip: download the new zip, unzip it and replace the old folder in the same place. Then open index.html in the same browser. Export a backup before you replace it, in case your browser treats the new folder as a new place.

Uninstall

Export your backup first. Then remove it the way you'd remove any app: on a computer, right-click the app → Uninstall, or use the app window's menu → Uninstall; on a phone, long-press the icon → Remove / Uninstall.

Need help?

Ask your instructor. Tell them which device and browser you're using.
